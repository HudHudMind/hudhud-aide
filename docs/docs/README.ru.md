**HudHud AIDE** представляет собой интегрированную среду разработки, созданную преимущественно для языка [**HudHudScript**](https://github.com/HudHudMind/hudhudscript), а также поддерживающую редактирование исходного кода и разработку проектов на современных языках программирования, таких как **Python, Rust, C/C++ и TypeScript/JavaScript**, с помощью встроенного редактора и AI-агента для написания кода.

Среда объединяет два взаимодополняющих рабочих процесса:
* **Редактирование кода и поддержка AI-агента:** Написание, диагностика и рефакторинг многоязычного исходного кода с помощью автономного AI-агента, осведомленного о контексте рабочего пространства.
* **Визуальное программирование (`.hudhudgraph`):** Нодовая система визуального программирования для моделирования, структурирования и генерации логики **HudHudScript** и мультиагентных пайплайнов.

HudHud AIDE объединяет **традиционную разработку программного обеспечения с современными парадигмами**:
* **Агентное программирование (Agentic Programming):** Определение и развертывание автономных агентов, ролей, интеграции инструментов и координации мультиагентных систем.
* **Инженерия циклов и цепочки циклов (Loop Engineering & Loop Chains):** Построение циклов выполнения с обратной связью, циклов валидации и цепочек итеративного улучшения.
* **Системы управления и правил (Governance):** Задание операционных ограничений, политик безопасности, правил валидации и прав доступа напрямую в коде и графах.
* **Субъектно-ориентированное программирование (SOP):** Структурирование архитектуры вокруг активных субъектов, контекстов и намерений вместо статичных объектов.

Инженеры и разработчики могут создавать собственные AI-агенты и архитектуры систем визуально через интерфейс визуального программирования, программно в исходном коде или совместно со встроенным AI-агентом.

## Ключевые возможности

```
┌─────────────────────────────────────────────────────────────┐
│                        HudHud AIDE                          │
├───────────────────┬─────────────────────┬───────────────────┤
│    Визуальное     │      AI-агент       │   HudHudScript    │
│  программирование │   (Осведомленный    │ (Оптимизированная │
│  (.hudhudgraph)   │    о контексте)     │  среда исполнения)│
└───────────────────┴─────────────────────┴───────────────────┘
```

* **Визуальное моделирование архитектуры и логики:** Проектирование потоков приложений, агентных пайплайнов и структур состояний с помощью нодового визуального программирования.

## Визуальное программирование и HudHudGraphs

**Визуальное программирование** в HudHud AIDE предоставляет интерактивный холст для визуального проектирования и анализа архитектуры программного обеспечения параллельно с исходным кодом.

Визуальные схемы сохраняются в стандартных файлах **`.hudhudgraph`**.

```
                    ┌─────────────────────────┐
                    │       Agent Node        │
                    ├───────────┬─────────────┤
                    │ Role      │ Governance  │
                    │ Tools     │ Validation  │
                    └─────┬─────┴──────┬──────┘
                          │            │
                          ▼            ▼
                   [ Action / Loop ] [ Policy ]
```

### Возможности:
* **Более 240 специализированных типов нод:** Готовые ноды для логики приложений, описания агентов, пайплайнов данных, конечных автоматов и правил управления.
* **Типизированные соединения:** Четкие каналы данных и потоки выполнения с типобезопасной валидацией пинов.
* **Инспектор свойств:** Выберите любую ноду для настройки ее параметров, поведения и атрибутов в реальном времени.
* **Гибридный рабочий процесс:** Совместное использование визуальных файлов `.hudhudgraph` и исходного кода `.hud` без накладных расходов на обязательную кодогенерацию.

### Порядок работы:
1. Откройте или создайте файл `.hudhudgraph` в рабочем пространстве.
2. Нажмите **«Open with Visual Designer»** на вкладке редактора.
3. Перетащите ноды из левой **Палитры** на холст.
4. Соедините пути выполнения и пины передачи данных между нодами.
5. Настройте свойства нод на правой панели и сохраните (`Ctrl + S` / `Cmd + S`).

## Встроенный AI-агент для кодинга

HudHud AIDE включает встроенного AI-ассистента, работающего напрямую в контексте вашего проекта.

### Основные задачи ассистента:
* **Анализ рабочего пространства:** Считывает и понимает файлы исходного кода, конфигурации проекта и архитектуры `.hudhudgraph`.
* **Многофайловая реализация:** Реализует функции и выполняет рефакторинг сразу в нескольких файлах за один проход.
* **Диагностика и устранение ошибок:** Определяет предупреждения компилятора, исключения среды исполнения и ошибки типов, предлагая проверенные исправления.
* **Автоматизация задач:** Выполняет многошаговые инженерные планы, запуски тестов и миграции проектов.

## Парадигмы языка HudHudScript

HudHud AIDE нативно поддерживает ключевые парадигмы языка [**HudHudScript**](https://github.com/HudHudMind/hudhudscript):

* **Агентное программирование (Agentic Programming):** Языковые конструкции для создания автономных агентов, ролей, обязанностей, инструментов и взаимодействия агентов.
* **Инженерия циклов (Loop Engineering):** Структурированные циклы исполнения с обратной связью, объединяющие действия, проверки и итеративное улучшение.
* **Системы управления (Governance):** Встроенные средства описания ролей, правил, ограничений, советов и прав доступа непосредственно в коде и графах.
* **Субъектно-ориентированное программирование (SOP):** Моделирование систем вокруг субъектов, контекстов и поведенческих обязанностей.

## Нативный набор инструментов HudHudScript

HudHud AIDE поставляется с полным набором нативных инструментов. При установке среда определяет инструкции процессора (SSE4.2, AVX2, AVX-512) и активирует соответствующий набор бинарных файлов (`x86-64-v1` to `v4`):

| Утилита | Назначение |
| :--- | :--- |
| **`hudhud`** | Среда исполнения командной строки (CLI) и запуска приложений |
| **`hudc`** | Нативный оптимизирующий компилятор HudHudScript |
| **`hudi`** | Интерактивная оболочка REPL и интерпретатор |
| **`hudconv`** | Утилита миграции AST, байт-кода и схем |
| **`hudhudscript-lsp`** | Сервер LSP для подсветки синтаксиса, автодополнения и документации |
| **`hudhud_ffi`** | Среда взаимодействия с внешними функциями C / Rust (FFI) |

## Единый рабочий процесс разработки

```
   1. Визуальное              2. Реализация              3. Проверка и
      программирование           в коде                     запуск
 ┌──────────────────────┐   ┌──────────────────────┐   ┌──────────────────────┐
 │ Моделирование графа  │──►│ Написание кода с     │──►│ Компиляция, тесты    │
 │ (.hudhudgraph)       │   │ AI-агентом           │   │ и запуск (hudc/hudi) │
 └──────────────────────┘   └──────────────────────┘   └──────────────────────┘
```

1. **Моделирование:** Проектируйте логику, агентов или пайплайны визуально с помощью визуального программирования.
2. **Реализация:** Пишите код на HudHudScript или работайте совместно с встроенным AI-агентом для реализации логики.
3. **Запуск и отладка:** Запускайте и тестируйте код прямо в IDE с помощью нативных инструментов и интерактивной отладки.

### Windows (x64)
* **ОС:** Windows 10 / 11 (64-bit)
* **Скачать:** [`hudhud-aide-v0.4.46-win-x64-setup.exe`](https://github.com/HudHudMind/hudhud-aide/releases/download/v0.4.46/hudhud-aide-v0.4.46-win-x64-setup.exe)
